# 📅 던전월드 일정 조율 시트

16명의 참가자가 가능한 시간을 입력하고, 히트맵으로 겹치는 시간을 한눈에 확인할 수 있는 웹 기반 일정 조율 도구입니다. 빌드 도구 없이 순수 HTML/CSS/JavaScript로 만들어져 GitHub Pages에서 바로 동작합니다.

## 🌐 사용하기

GitHub Pages가 활성화되어 있다면 아래 주소에서 바로 사용할 수 있습니다:

> https://hwiyoungkim.github.io/Dungen-World-Time-Table-Making/

로컬에서 사용하려면 `index.html`을 브라우저로 열기만 하면 됩니다.

## ✨ 주요 기능

- **16명 참가자 관리** — 참가자를 선택하고 "이름 변경" 버튼으로 이름을 수정할 수 있습니다.
- **클릭/드래그 시간 입력** — 요일(월~일) × 시간대(09:00~24:00) 그리드에서 셀을 클릭하거나 드래그해서 가능한 시간을 체크합니다. 다시 클릭/드래그하면 해제됩니다. 모바일 터치도 지원합니다.
- **히트맵 뷰** — 전체 참가자의 가능 시간을 겹쳐 보여줍니다. 색이 진할수록 가능한 인원이 많으며, 셀 안의 숫자가 가능 인원수입니다. 셀을 클릭하면 가능한 사람 목록이 표시됩니다.
- **최적 시간 TOP 5** — 가장 많은 인원이 가능한 시간대를 자동으로 추천합니다.
- **자동 저장** — 입력한 데이터는 브라우저의 localStorage에 자동 저장되어 새로고침해도 유지됩니다.
- **JSON 내보내기/가져오기** — 데이터를 파일로 공유할 수 있습니다.

## 📖 사용 방법

### 1. 내 시간 입력하기
1. **✏️ 내 시간 입력** 탭에서 자기 참가자를 선택합니다.
2. **이름 변경** 버튼으로 본인 이름을 입력합니다.
3. 그리드에서 가능한 시간을 클릭 또는 드래그로 체크합니다 (보라색 = 가능).

### 2. 전체 일정 확인하기
1. **🔥 전체 히트맵** 탭을 누릅니다.
2. 색이 진한 셀일수록 많은 사람이 가능한 시간입니다.
3. 셀을 클릭하면 해당 시간에 가능한 사람 목록이 나옵니다.
4. 아래 **최적 시간 TOP 5**에서 추천 시간을 확인합니다.

### 3. 참가자 간 데이터 공유하기

데이터는 각자의 브라우저에만 저장되므로, 다른 사람과 합치려면 JSON 파일을 주고받아야 합니다.

1. 각자 자기 시간을 입력한 뒤 **📤 JSON 내보내기**로 파일을 저장합니다.
2. 파일을 한 사람(총무)에게 보냅니다.
3. 총무가 **📥 JSON 가져오기**로 각 파일을 불러옵니다.
   - **확인**을 누르면 기존 데이터와 **병합**됩니다 (여러 명의 파일을 순서대로 합칠 때 사용).
   - **취소**를 누르면 기존 데이터를 완전히 **교체**합니다.
   - ⚠️ 병합은 참가자 번호(1~16) 기준이므로, 각자 **서로 다른 참가자 번호**를 사용해야 합니다. (예: 철수는 참가자 1, 영희는 참가자 2)
4. 합쳐진 히트맵을 확인하고, 필요하면 다시 내보내서 모두에게 공유합니다.

## 🛠️ GitHub Pages 수동 활성화 방법

Pages가 아직 활성화되지 않았다면:

1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Source**를 `Deploy from a branch`로 선택합니다.
3. **Branch**를 `main`, 폴더를 `/ (root)`로 선택하고 **Save**를 누릅니다.
4. 잠시 후 `https://hwiyoungkim.github.io/Dungen-World-Time-Table-Making/`에서 접속할 수 있습니다.
