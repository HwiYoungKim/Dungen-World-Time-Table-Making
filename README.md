# 📅 모임 일정 조율

여러 개의 모임 일정을 캘린더 기반으로 조율하는 웹 도구입니다. 참가자들이 **시간을 낼 수 있는 날짜**를 캘린더에서 체크하면, 기준 인원 이상 모일 수 있는 날짜를 자동으로 찾아 보여줍니다. 빌드 도구 없이 순수 HTML/CSS/JavaScript로 만들어져 GitHub Pages에서 바로 동작합니다.

## 🌐 사용하기

> https://hwiyoungkim.github.io/Dungen-World-Time-Table-Making/

로컬에서는 `index.html`을 브라우저로 열기만 하면 됩니다.

## ✨ 주요 기능

- **여러 일정 관리** — 홈에서 "➕ 새로운 일정 관리하기"로 일정을 여러 개 만들어 관리할 수 있습니다. 기본으로 **던전월드 일정 조율**(16명 고정 명부, 2026년 9월, 3인 이상 기준)이 만들어져 있습니다.
- **날짜 기반 체크** — 요일이 아닌 **실제 날짜**(예: 2026년 9월 2일)를 캘린더에서 클릭해 체크합니다. ⚠️ **체크한 날짜는 "시간을 낼 수 있는 날"로 취급됩니다.**
- **🌐 실시간 공유 (중앙 서버 동기화)** — 기본 제공되는 **던전월드 일정은 사이트에 접속만 하면 코드 입력 없이 자동으로 서버에 연결**되어 모두가 같은 데이터를 봅니다. 직접 만든 새 일정은 [공유/설정]에서 **공유 코드**를 만들어 나눠주면 함께 볼 수 있습니다. 체크·월 변경 후 상단 **💾 저장** 버튼으로 서버에 업로드하고, 다른 사람은 🔄 새로고침으로 받아옵니다.
- **월 추가** — 10월/11월 일정을 추가로 받아야 하면 [공유/설정] 탭에서 다음 달을 추가할 수 있습니다. 기존 체크 기록은 그대로 유지되고, 공유 중이라면 **모두에게 확장이 반영**됩니다.
- **월 삭제(조회 중단)** — 실수로 기간을 늘렸다면 [공유/설정]에서 **~년 ~월부터 ~년 ~월까지** 범위를 골라 한 번에 여러 달을 중단할 수 있습니다. ⚠️ 삭제 전 `지우겠습니다`를 정확히 입력해야 하며, 해당 기간에 기입된 체크는 **복구 불가능하게 초기화**됩니다. 최소 한 달은 남아 있어야 합니다.
- **가능한 날짜 자동 계산 (기본 화면)** — 일정을 열면 바로 캘린더 히트맵(진할수록 많은 인원, 초록 테두리 = 기준 충족)이 보이고, 기준 인원(기본 3인) 이상이 가능한 **모든 날짜**를 "9월 2일 (수) — 가능인원 N명: [이름들]" 형식으로 나열합니다. 최다 인원 날짜에는 🏆 표시.
- **이름 자동 정리** — 새 일정 참가자 입력 시 **중복 이름은 자동 제거**되고, `예ㅐ시`처럼 완성되지 않은 한글(자음/모음만 있는 글자)이 있으면 알림으로 재입력을 요청합니다.
- **💾 수동 저장 + 나갈 때 자동 업로드** — 날짜를 체크하면 상단 버튼이 **💾 저장 (N)** 으로 바뀝니다. 누르면 즉시 서버에 업로드되고, 누르지 않아도 **페이지를 닫거나 다른 화면으로 이동하면 자동으로 업로드**됩니다. 저장 안 된 변경은 기기에 보관되어 다음 접속 때도 유지됩니다.
- **수동 새로고침 + 자동 동기화** — 사이트에 들어오거나 다른 앱을 봤다가 돌아오면 **자동으로 최신 데이터를 받아오고**, 화면을 켜 둔 동안에도 몇 분마다 자동 갱신됩니다. 즉시 확인하고 싶으면 상단 🔄 버튼을 누르세요.
- **일정 삭제** — 일정을 **만든 사람(만든 기기)**만 [공유/설정] 탭에서 삭제할 수 있습니다.
- **다크/라이트/자동 테마** — 상단 🌓 버튼으로 전환. 시스템 설정(자동)도 지원합니다.
- **반응형** — 아이폰/갤럭시/태블릿/PC 모두 지원.

## 📖 사용 방법

### 1. 내가 가능한 날짜 체크하기
1. 홈에서 일정을 선택합니다.
2. **✏️ 날짜 체크** 탭에서 내 이름을 선택합니다.
3. 캘린더에서 **시간을 낼 수 있는 날**을 눌러 체크합니다 (다시 누르면 해제).

### 2. 결과 확인하기
1. **🗓️ 가능한 날짜 보기** 탭을 누릅니다.
2. 기준 인원 이상 가능한 모든 날짜가 인원·이름과 함께 나열됩니다.
3. 아래 캘린더에서 날짜를 누르면 그날 가능한 사람 목록이 나옵니다.

### 3. 새 일정 만들기
1. 홈에서 **➕ 새로운 일정 관리하기**를 누릅니다.
2. 일정 이름, 참가자 명단(인원 수), 조사할 기간(시작 월 + 개월 수, 기본값은 현재 달), 기준 인원을 설정합니다.
3. 만든 뒤에는 언제든 홈에서 다시 들어가 결과를 조회할 수 있습니다.

### 4. 참가자 간 데이터 공유
**기본 던전월드 일정**은 아무 설정 없이 접속만 하면 자동으로 같은 데이터를 공유합니다.

**직접 만든 새 일정**을 함께 쓰려면 공유 코드를 사용합니다:
1. 일정을 만든 사람이 [⚙️ 공유/설정] → **🌐 공유 코드 만들기**를 누르고, 표시된 코드를 단톡방 등에 공유합니다.
2. 다른 참가자는 홈의 **공유 코드로 일정 가져오기**에 코드를 붙여넣고 [가져오기]를 누릅니다.
3. 이후 각자 체크하고 **💾 저장**을 누르면 서버에 업로드되며(페이지를 나갈 때는 자동 업로드), 🔄 새로고침으로 다른 사람의 최신 체크를 받아옵니다.
4. 월 추가/삭제도 모두에게 동일하게 반영됩니다.

> 서버 동기화는 무료 공개 API(restful-api.dev)를 사용합니다. 대신 **GitHub Actions가 6시간마다 모든 공유 일정 데이터를 이 저장소(`data/backups/`)에 자동 커밋**하여 장기 보존합니다. 임시 서버에서 데이터가 사라져도 앱이 GitHub 백업에서 자동 복구하고 새 공유 코드를 발급합니다 (git 이력으로 과거 기록도 추적 가능).

#### 백업: JSON 파일로 공유
1. [⚙️ 공유/설정] → **📤 JSON 내보내기**로 파일 저장 후 전달.
2. 받은 사람이 **📥 JSON 가져오기**로 불러오면 **이름 기준으로 자동 병합**됩니다.

## 🛠️ GitHub Pages 수동 활성화 방법

1. 저장소 **Settings → Pages** 이동
2. **Source**: `Deploy from a branch`
3. **Branch**: `main`, 폴더 `/ (root)` 선택 후 **Save**

## 📁 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 페이지 뼈대 |
| `style.css` | 스타일 (라이트/다크 테마, 반응형) |
| `app.js` | 일정 관리, 캘린더 렌더링, 결과 계산, 중앙 서버 동기화, 저장/공유 로직 |
| `data/sync-registry.json` | 백업 대상 공유 코드 레지스트리 정보 |
| `data/backups/` | GitHub Actions가 자동 커밋하는 일정 데이터 장기 백업 |
| `.github/workflows/backup.yml` | 6시간마다 동기화 데이터를 저장소에 백업하는 워크플로 |
